# Logos

- `velowood-logo.png` — the wordmark in walnut with the honey tree-ring "o", on a transparent ground. Use on paper, linen and honey-soft. Minimum height 20px on screen.
- `velowood-logo-reverse.png` — the same wordmark with paper letters, the tree ring left in its own colours. Use on walnut and walnut-deep only.
- `velowood-logo-original.jpg` — the logo exactly as the client supplied it (JPG on white). Source file; don't use it on the site.
- `velowood-ring-mark.png` — the tree-ring "o" cut out on its own: favicon, avatar, the disc on the hero photo. Never with the word next to it.

These are raster files made from the logo the client supplied (white removed, letters recoloured for the reverse). Ask for the vector original before launch. Never redraw, recolour, stretch or outline the mark.
