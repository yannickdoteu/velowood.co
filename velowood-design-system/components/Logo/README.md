# Logo

The velowood wordmark: lowercase geometric letters in walnut, with the "o" drawn as a cross-section of a tree trunk in honey. Three versions live in `assets/Logos`.

- Use `velowood-logo.png` (primary) on paper, linen and honey-soft; `velowood-logo-reverse.png` on walnut and walnut-deep only.
- Use `velowood-ring-mark.png` alone for the favicon, social avatars and the disc on the hero photo; never beside the word.
- Keep clear space equal to the height of the ring "o" on every side; minimum height 20px (header 26px, footer 24px).
- Never recolour, outline, add shadows to, stretch or redraw it. `velowood-logo-original.jpg` is the file as the client supplied it; replace all of these with the vector original before launch.
