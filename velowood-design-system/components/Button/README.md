# Button

Pill-shaped actions with the soft, rounded ends of the wordmark. Classes: `vw-btn` (primary, walnut fill), `vw-btn--secondary` (walnut outline), `vw-btn--sm` (40px, header), and on walnut grounds `vw-btn--light` (paper fill) and `vw-btn--ghost-light`. `vw-link` is the inline text link in `bark`.

- Provide: an `<a>` or `<button>` with a short label, sentence case, verb first ("Discover the bicycles", "Get in touch"). Add the 16px arrow SVG (`.vw-arrow`) only to the one action that moves the visitor forward.
- One primary per view. Pair it with at most one secondary.
- On a walnut section use only the `--light` versions; never a walnut button on walnut.
- Focus: 2px `focus` ring at 2px offset (`focus-on-walnut` inside dark sections).
