# Pillars

The five advantages of wood, as a numbered grid: three on top, two centred below, each with a small tree-ring numeral, a `heading-3` title and a short paragraph in `ink-muted`, divided by `line` hairlines.

- Provide: an `<ol class="vw-pillars">` of `vw-pillar` items with an empty `vw-pillar__num` span, an `<h3>` and a `<p>`. Numbers come from a CSS counter.
- Built for five items; for three, drop the `:nth-child(4)` offset. One column on mobile.
- Keep the client's own wording for the claims.
